# THE RAY — BRAND SYSTEM

## Source of truth
Use the supplied The Ray logo as the visual reference.

### Core brand colors
- Blue: #0427F3
- Purple midpoint: #6A2BBF
- Magenta/Pink: #CD127B
- Dark logo/text: #373435

### Primary gradient
linear-gradient(135deg, #0427F3 0%, #6A2BBF 52%, #CD127B 100%)

## Critical rule
Brand colors are accents, NOT full-screen UI colors.

Do NOT use #0427F3 as the default background for cards, pages, charts, or large containers.
The logo can be vivid; the application should be calm.

## Visual personality
Premium • calm • tactile • modern • business-first • soft 3D • restrained motion

Avoid:
- neon-heavy UI
- rainbow gradients
- random blue cards
- glassmorphism everywhere
- cartoonish 3D
- mixing unrelated icon styles
