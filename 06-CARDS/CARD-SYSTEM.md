# CARD DEPTH SYSTEM

## Base card
surface + 1px subtle border + low shadow

## Elevated card
surface-elevated + stronger shadow + tiny top/inner highlight

## Gradient card
Use brand gradient only as a restrained edge, icon background, KPI highlight, or progress element.
Never fill an entire dense dashboard with saturated blue.

## 3D card formula
1. calm surface
2. soft radial highlight near icon
3. 3D icon
4. strong KPI
5. secondary context
6. micro-chart/progress
7. hover lift 2–4px

## KPI card
Icon + label + value + delta + tiny trend.

## Action card
3D icon + title + one-line description + optional right arrow.

## Avoid
- giant blue rectangles
- excessive borders
- equal visual weight for every card
- 10 different card shapes
