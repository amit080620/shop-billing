# Spacing / Grid

Base unit: **4px**.

Allowed spacing values:
4, 8, 12, 16, 20, 24, 28, 32, 40, 48, 64, 80px.

Do not invent arbitrary spacing unless a real layout constraint requires it.

Typical:
- icon-to-label: 8px
- form field gap: 16px
- card internal padding: 20–24px
- section gap: 24–32px
- page section gap: 32–48px
- desktop page horizontal padding: 24–40px
- mobile page horizontal padding: 16px
