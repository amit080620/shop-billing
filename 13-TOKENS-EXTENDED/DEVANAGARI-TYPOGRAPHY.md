# Hindi / Devanagari Typography

Hindi is a first-class UI language.

Preferred font stack:
`Inter, Noto Sans Devanagari, Noto Sans, system-ui, sans-serif`

For invoice/print where Devanagari is present:
`Noto Sans Devanagari, Noto Sans, sans-serif`

Rules:
- body line-height: 1.45–1.6
- labels: minimum 12px
- dense invoice text: 10–12px print size
- allow extra vertical space for Devanagari glyphs
- never clip matras
- test Hindi + English mixed strings
- currency and numeric values stay visually aligned
