# Icon Source Strategy

## 3D business icons
Use official/licensed 3D icon libraries only. Recommended starting point:
3dicons (official): https://3dicons.co/

Verify the current license before adding assets to the project. Keep the downloaded asset set inside the project only as permitted by its license.

## Utility icons
Use one consistent 2D SVG family for tiny UI controls. Do not mix multiple outline icon libraries on the same screen.

## Motion
Use CSS/SVG for micro-interactions where possible. For third-party Lottie assets, verify the individual asset license before use and do not redistribute standalone assets outside permitted terms.
