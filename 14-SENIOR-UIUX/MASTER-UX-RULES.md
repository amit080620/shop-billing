# Senior Product UX Rules

1. One primary action per screen/section.
2. Reduce cognitive load before adding visual decoration.
3. Dense business data stays readable; 3D is used for meaning and emphasis.
4. Every action has a visible state: idle, working, success, error.
5. Destructive actions require clear confirmation when irreversible.
6. Forms should preserve user input after validation errors.
7. Tables must support scanning: aligned numbers, sticky headers where needed, clear row actions.
8. Empty states must explain what happened and what the user can do next.
9. Loading states must represent the actual operation, not a generic spinner everywhere.
10. Mobile layouts must be recomposed, not merely compressed desktop layouts.
11. Dark mode must reduce glare: surfaces are dark neutral; brand blue is an accent.
12. Hindi/English mixed text must never clip or create awkward line-height.
13. Accessibility: keyboard focus, readable contrast, 44px touch targets, reduced motion.
14. Never sacrifice billing accuracy or print clarity for visual effects.
