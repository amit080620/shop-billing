# 3D ICON SYSTEM

## Strategy
Do NOT make every tiny UI icon 3D.

### Tier A — Core business actions (3D)
Use 3D/2.5D objects for:
Billing, Print Bill, Payment, Orders, Products, Inventory, Customers, Vendors,
Catalog, Restaurant/KDS, Pharmacy, Clinic, Gym, Salon, Service Jobs, Reports,
Refund, Stock In/Out, Barcode, Scanner, Cash, Wallet, GST, Appointments.

### Tier B — navigation/support (2D)
Use simple consistent SVG icons for:
close, chevron, back, menu, search, filter, sort, edit, plus, minus, settings,
notifications, calendar, help, more, upload/download.

### Tier C — empty states
Large 3D illustration + short message + one action.

## 3D visual rules
- Rounded 2.5D/3D geometry
- Consistent perspective
- Soft depth
- Soft ambient shadow
- Light direction consistent across all icons
- Main accent: #0427F3 → #6A2BBF → #CD127B
- Use neutral white/grey highlights for material depth
- Transparent background
- No unrelated yellow/green/orange icon packs unless the object itself requires a tiny natural detail

## Size
- Navigation: 28–32px visual object
- Feature tile: 44–56px
- Dashboard hero: 64–88px
- Empty state: 120–220px

## Important
The icon should explain the business action at a glance. Do not choose an abstract icon when a recognizable 3D object is better.
