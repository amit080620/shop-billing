# TYPOGRAPHY

Use one clean UI family consistently. Prefer Inter or the project's existing modern sans-serif if already installed.

Hierarchy:
- Display: 32/40, 700
- H1: 28/36, 700
- H2: 22/30, 650
- H3: 18/26, 650
- Body: 14/20, 450
- Small: 12/18, 450
- Label: 12/16, 600
- Numeric KPI: 28/34, 700

Rules:
- Never use more than 3 weights on one screen.
- Avoid oversized headings in dense business workflows.
- Numeric values should have strong contrast and consistent tabular alignment.
- Do not change typography screen-by-screen.
