# RESPONSIVE RULES

Mobile:
- one primary action per screen
- bottom-sheet patterns for filters/forms where appropriate
- cards stack
- dense tables become cards or horizontal scroll
- touch target >= 44px
- do not shrink desktop UI until unreadable

Desktop:
- preserve information density
- sidebar + content
- max content width where useful
- use whitespace around groups

TV/Kitchen:
- large typography
- high contrast
- fewer controls
- auto-refresh only where business logic requires it
