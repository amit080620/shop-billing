# EMPTY STATE SYSTEM

Every empty state has:
1. one recognizable 3D illustration
2. short title
3. one sentence explaining why
4. one primary next action
5. optional secondary action

Examples:
No Products → 3D shelf/box → "Add your first product" → Add Product
No Customers → 3D customer card → "Add a customer" → Add Customer
No Bills → 3D invoice/printer → "Create your first bill" → New Bill
No Sales → 3D chart → "Sales will appear here" → Create Bill
No Inventory → 3D boxes/shelf → "Stock is empty" → Add Stock
No Reports → 3D dashboard → "Generate a report" → Reports
